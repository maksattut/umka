# 90s NIGHT — Local Music GitHub Pages

Это версия плеера без внешних музыкальных API.

## Как добавить музыку

1. Откройте папку `music`.
2. Положите туда свои MP3-файлы.
3. Откройте `index.html`.
4. В массиве `tracks` укажите точные имена файлов.

Пример:

```js
{title:"My Song", artist:"My Artist", file:"music/my-song.mp3"}
```

Имя в `file` должно совпадать с названием файла в папке `music`.

## Публикация

Загрузите на GitHub:
- `index.html`
- папку `assets`
- папку `music` со своими MP3

После этого включите GitHub Pages из Settings → Pages → Deploy from branch.

## Важно

Используйте только музыку, которую вы имеете право размещать и распространять.
